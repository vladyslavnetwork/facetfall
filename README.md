# Facetfall

Геометричний арканоїд у дусі ігор 1980-х: ракетка, м'яч і стіна з гранованих блоків.
Python + pygame-ce.

- **50 рівнів** зі зростаючою складністю, контрольна точка кожні 5 рівнів
- Блоки: звичайні, міцні (2–3 удари), сталеві (незламні), вибухові
- **15 бонусів**: три м'ячі, широка ракетка, щит, повільний м'яч, липка ракетка,
  додаткове життя, лазер, магніт, вогняна куля, мега-м'яч, розщеплення м'ячів,
  бонусні очки; і три, яких краще уникати: вузька ракетка, швидкий м'яч,
  обернене керування. Що далі рівень — то частіше випадають сильні бонуси
  і тим довше вони діють.
- Комбо: кожен блок без дотику до ракетки збільшує множник очок
- Мови: English, Українська, Polski, Deutsch, Français, Español

## Керування

| Дія | Клавіші |
|---|---|
| Рух ракетки | миша або ← → / A D |
| Запуск м'яча, постріл лазером | клік або Пробіл |
| Пауза | P / Esc |
| Повний екран | F11 |

## Запуск із вихідного коду

```bash
sudo apt install python3-venv gettext
./tools/compile_translations.sh
python3 -m venv .venv && . .venv/bin/activate
pip install -e .
facetfall --windowed
```

```

src/facetfall/sound.py     синтезовані звуки

snap/                      пакування для Snap Store
```
